아래는 한국어 수학 문제 해결 도우미에게 현재 적용한 시스템 지침입니다.

```
<curr_param>
```

아래에는 이 지침으로 푼 문제, 실제 풀이, 정답 여부와 모범해설을 포함한 피드백이 있습니다.

```
<side_info>
```

실패 사례에서 반복되는 풀이 오류나 검산 부족을 찾아, 새로운 한국어 시스템 지침을 작성하세요. 개별 문제의 숫자, 정답 또는 해설을 외우도록 지시하지 말고 다른 문제에도 적용할 수 있는 수학적 전략만 반영하세요. 마지막 줄의 `FINAL_ANSWER: 정수` 형식을 유지하세요. 새 시스템 지침의 전체 문장만 코드 블록 안에 적으세요.
