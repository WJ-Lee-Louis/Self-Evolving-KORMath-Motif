아래는 한국어 수학 문제 해결 도우미에게 현재 적용한 시스템 지침입니다.

```
<curr_param>
```

아래에는 이 지침으로 푼 문제, 도우미의 응답, 정답 여부와 구체적인 피드백이 있습니다.

```
<side_info>
```

실패 사례에서 반복되는 원인을 찾아, 새로운 한국어 시스템 지침을 작성하세요. 특정 문제의 숫자나 정답을 외우게 하지 말고, 다른 한국어 수학 문제에도 적용할 수 있는 풀이 및 검산 전략을 반영하세요. 최종 답은 마지막 줄에 `정답: 숫자` 형식으로 쓰도록 유지하세요. 새 시스템 지침의 전체 문장만 코드 블록 안에 적으세요.
